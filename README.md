# GTA-Like-City：夕陽小房間

一間可以走進去逛的 3D 小房間。裡面住了兩個人，有會動的太陽和月亮，還有一個小小的物理引擎。

打開 `index.html` 就能玩（需要網路，因為 3D 引擎 three.js 是從網路載入的）。

## 怎麼玩

| 你想做的事 | 電腦 | 手機 |
| --- | --- | --- |
| 走路 | `W` `A` `S` `D`，按住 `Shift` 會跑 | 左手拖 |
| 轉頭 | 點畫面鎖定滑鼠後移動滑鼠 | 右手拖 |
| 踢球 | 走近球，點它 | 點球 |
| 跟人打招呼 | 點那個人 | 點那個人 |
| 開關燈、電視 | 點它，或按左上角按鈕 | 同左 |

## 裡面有什麼

### 住在這裡的人
- **小美**：白天上班。早上伸展、看海，傍晚照顧盆栽、看電視，晚上跳舞、看書，半夜睡沙發。
- **阿傑**：上夜班。早上回家看日出、看書，白天睡沙發，下午踢籃球，晚上跟小美一起看電視。
- 他們會自己找路繞過家具，天黑會開燈，沒人看電視會關掉。你擋住路，他們會停下來看你。

### 物理
- **重力**：球會往下掉、會彈。可以切換 地球 / 月球 / 無重力。
- **吸引力**：打開「引力球」，它會把別的球吸過來。公式是 `F = G·m1·m2 / r²`。
- **作用力與反作用力**：兩個東西相撞，各自被推一樣大、方向相反的力。輕的跑得快，重的幾乎不動。左上角會寫出每次碰撞誰推了誰、推多大。
- 限制：只有球是真的物理物體。家具不會被撞動，人也不會被球撞倒。

### 時間和光影
- 時鐘會自己走（預設 1 秒 = 遊戲裡 2 分鐘），可以暫停、快轉，或拉滑桿直接跳到某個時間。
- 太陽和月亮會移動，影子、天空顏色、房間亮度跟著變。

## 檔案

- `room.html`：全部的程式（畫面、物理、人物都在這一個檔案）。
- `index.html`：把 `room.html` 包成完整網頁，給瀏覽器直接開。
- `build.py`：改完 `room.html` 之後跑 `python3 build.py`，會重新產生 `index.html`。
