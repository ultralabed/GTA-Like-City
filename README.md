# GTA-Like-City：夕陽街

一條可以走進去逛的 3D 小街：8 間房子、1 間商店、13 個住戶、馬路、公園和海灘。每間房子都可以開門走進去。裡面的人自己決定要做什麼，有會動的太陽和月亮，還有一個小小的物理引擎。

**線上玩：https://ultralabed.github.io/GTA-Like-City/** （推到 `main` 會自動更新）

也可以在自己電腦打開 `index.html`（需要網路，因為 3D 引擎 three.js 是從網路載入的）。

### 可以拿來用的東西
- **手機地圖**：一開始就有。從上面看整條街：房子和門牌、馬路、每個人在哪、車子、你自己（白色箭頭）。
- **手電筒**：在每間房子客廳的電視櫃上。晚上很有用。
- **雨傘**：在每間房子大門旁邊。下雨時撐開，雨就不會落在你身上。
- 手電筒和雨傘一次只能拿一樣；手上拿球時兩樣都會收起來。

### 說話、任務、錢
- 點一個人會出現對話框，可以選：打招呼、問他在做什麼、問要不要幫忙、請他喝飲料。
- 問「需要幫忙嗎？」他可能給你一個**任務**，做完會拿到錢：
  - **送信**給別家的人（$50）
  - **拿一顆球**給他（$40）
  - **在商店打工送貨**：點收銀機選「打工：幫忙送貨」。要在時間內把包裹送到某一家門口，工資 $30，越快到獎金越多（最多再加 $40）。騎腳踏車比較來得及。
  - **開車載他**去公園、商店或街的另一頭（$60）。他會自己走到你的黃色車旁邊等你；你上車他就坐進來，開到目的地停車他就下車。
- **居民會記得你**：每個人心裡對你有一個「好感」。幫他做事、請他喝飲料、常跟他說話會變好（對話框裡會出現 ♥）；用球丟他、開車嚇他會變差。好感高的人看到你會主動揮手；好感很差的人不想跟你說話，要先道歉。
- **居民之間也會聊天**：兩個人在路上遇到會停下來講兩句話，內容會看天氣、時間和對象而不同。
- 任務會顯示在左上角；打開手機地圖，目標那個人身上會有橘色圓圈。
- **錢**：一開始有 $60。販賣機在公園旁邊和 5 號房子前面。
- **夕陽商店**（8 號，街的東邊）：走進去點收銀機，可以買飲料 $20、手電筒 $60、雨傘 $50。店員小芳不在時不能結帳。居民和路人也會進去逛。
- **體力**：跑步會消耗，走路和坐下會恢復，喝飲料直接補滿。體力用完就不能跑。
- **名聲**：做任務、請人喝飲料會變好；用球丟人、開車嚇人會變差。名聲太差，大家不想跟你說話。

### 巡邏員和星星
- 街上有一位**巡邏員阿國**，整天在街上走來走去。
- 你每次用球丟到人、或開車騎車嚇到人，就多一顆星（最多 3 顆，顯示在左上角）。
- 有星星時，巡邏員會走過來找你，星星越多他走越快。被他追到會被罰錢，一顆星 $25。
- 45 秒沒再闖禍，星星會少一顆。

### 紅綠燈
斑馬線兩頭有紅綠燈。車子紅燈會停，路人會等小綠人亮了才過馬路。不在斑馬線過馬路的人，還是會先等車子過。

### 自動存檔
遊戲大約每 10 秒自動存一次：時間、錢、名聲、背包、你的位置、車子停在哪。下次打開會接著玩。想從頭來，按設定裡的「重新開始」。

### 睡覺讓時間快轉
走到任何一張沒人睡的床或沙發旁邊，按 `Z` 躺下。時間會過得很快，早上 7 點自己醒來（動一下也會醒），醒來體力全滿。

### 小黃（狗）
3 號老陳家養了一隻狗叫小黃，平常在門口等。
- 看到會動的球，牠會衝過去用鼻子頂著球跑（追一陣子會累，休息一下）。
- 老陳出門時牠會跟著。你走近牠會過來想跟你玩，點牠可以摸摸牠。
- 你身上有星星時，牠會對你叫。晚上牠會回門口趴著睡。
- 牠過馬路也會等車，車子看到牠也會停。

### 下雨時的人
有帶傘的人會撐起傘繼續走；沒帶傘的人會嚇一跳、用跑的回家。

### 拍照模式和畫質
- 按 `P`（或設定裡的「拍照模式」）把畫面上的按鈕全部藏起來，方便截圖。
- 設定裡的「畫質」可以選高、中、低。跑不順的時候選低。

### 聲音
腳步聲、球彈跳聲、車子引擎和喇叭、開關門、下雨聲。全部是程式現場做出來的，沒有音效檔。要先點一下畫面才會有聲音。可以在設定裡關掉。

### 配樂
不同場景會自動換不同的音樂，換的時候舊的淡出、新的淡入。

| 場景 | 什麼時候播 | 感覺 |
| --- | --- | --- |
| 在家 | 你在任何一間房子裡 | 慢慢的、放鬆 |
| 白天的街 | 白天在外面 | 輕快 |
| 黃昏 | 傍晚或清晨在外面 | 合成器、有節奏 |
| 深夜 | 晚上在外面 | 很安靜、只有長音 |
| 下雨天 | 下雨時在外面 | 慢、有點憂鬱 |
| 兜風 | 開車的時候 | 有鼓、有衝勁 |
| 商店裡 | 在夕陽商店裡 | 輕鬆的店內音樂 |
| 被巡邏員追 | 身上有星星的時候 | 很快、很緊張 |
| 海邊 | 白天在海灘那一側 | 柔和、慢 |

開車時按 `R`（或右下角「收音機」）可以自己選台：兜風、黃昏、白天的街、商店裡、海邊、關掉。

旋律都是為這個遊戲寫的，由程式現場演奏，沒有音樂檔。設定裡可以關掉音樂（音效還在）。

### 第三人稱視角
按 `V` 可以退到自己背後，看到自己的角色（黃上衣）。角色會朝你走的方向轉身、走路、坐下、躺下，手上拿球或撐傘也看得到。鏡頭被牆擋到時會自己靠近，不會穿牆。再按一次 `V` 回到第一人稱。

### 游泳
走過沙灘往海裡走，水會越來越深，最後只剩頭和肩膀露出水面。在水裡走得比較慢、有潑水聲，游泳會慢慢消耗體力；體力用完，海浪會把你推回岸邊。車子和腳踏車不能開進海裡，居民和小黃也不會下水。

### 換衣服
點任何一個衣櫃（每間房子的臥室都有）就會換一套衣服，總共 5 套。按 `V` 切到第三人稱可以看到自己穿什麼。

### 設定面板
按左上角「設定」才會出現，再按一次收起來。裡面有：時間滑桿和快轉、天氣、最近那間房子的燈和電視、重力和引力球、居民的想法、操作說明。

## 裡面有什麼

### 住在這條街的人
| 門牌 | 誰 | 特色 |
| --- | --- | --- |
| 1 號 | 小美、阿傑 | 小美白天上班、有耐心；阿傑上夜班、愛玩 |
| 3 號 | 老陳、秀蘭 | 退休了，不用上班，喜歡安靜和照顧盆栽 |
| 5 號 | 小安 | 很早出門，愛玩 |
| 2 號 | 大衛、莉莉 | 大衛早班、愛運動；莉莉下午班 |
| 4 號 | 阿明 | 上班到晚上 |
| 7 號 | 阿豪、佩佩 | 阿豪愛玩愛運動；佩佩有耐心 |
| 9 號 | 小芳 | **在夕陽商店當店員**，早上 9 點到晚上 8 點顧店 |
| 6 號 | 志明、春嬌 | 志明白天班；春嬌下午到晚上 |
| 8 號 | （夕陽商店） | 沒人住，是一間店 |

- 他們會**走出家門**：去上班（走到街的盡頭）、散步、去公園坐長椅、去海邊看海，然後走回家。
- 走路會走人行道，過馬路會走斑馬線，進出會自己開門關門。
- 另外有 3 個**外地路人**（阿寬、婷婷、老王）：從街的一頭走進來，去公園或海邊，再從另一頭離開。

### 車子和天氣
- 馬路上有車，兩個方向各一個車道。車子看到路上有人會停下來；有人在斑馬線邊等，車子會禮讓。你擋在車前面太久，它會按喇叭。
- 路人過馬路前會先看車，有車要來就在路邊等。
- 會下雨（自己來，或按「天氣」按鈕）。一下雨，外面的人會嚇一跳，放下手邊的事，用跑的回家；地面會變濕變亮。
- 他們**沒有固定時間表**（只有上班時間是固定的）。每個人有 6 個「需要」：體力、吃飽、好玩、運動、平靜、照顧。
- **會肚子餓**：餓了會坐在客廳地毯上吃點心，或走去公園的小吃攤坐著吃。越餓越急。需要會慢慢變少，他們會挑最缺的那個去補。
- 每件事都有**目標**：例如「看書」要看滿 1.2 小時、「踢籃球」要踢到 3 下、「睡覺」要睡到體力滿。名牌上會顯示完成幾 %。
- **被打斷會有不同反應**，看是什麼事、是誰、心情好不好、第幾次：
  - 你打招呼 → 心情好會揮手，心情差會說不想講話。
  - 你關電視 → 第一次會抗議然後自己開回來，第二次就放棄去做別的事。
  - 你用球踢到人 → 阿傑會加入一起踢，踢完再回去做原本的事；小美會警告你，第三次就生氣走開。
  - 睡覺時吵他 → 第一次沒醒，第二次抱怨，第三次睡不著起來。
  - 你擋路 → 會說借過；有耐心的人等比較久。
  - 天黑你關燈 → 會說好暗，然後開回來。
- 按「想法」按鈕，可以看到每個人現在的目標和 5 個需要的數字。

### 物理
- **重力**：球會往下掉、會彈。可以切換 地球 / 月球 / 無重力。
- **吸引力**：打開「引力球」，它會把別的球吸過來。公式是 `F = G·m1·m2 / r²`。
- **作用力與反作用力**：兩個東西相撞，各自被推一樣大、方向相反的力。輕的跑得快，重的幾乎不動。左上角會寫出每次碰撞誰推了誰、推多大。
- **撿和丟**：每顆球用一樣大的力丟。網球飛很快，保齡球只飛一點點，30 公斤的引力球搬不動。
- **跳**：跟球用同一個重力。切到月球重力，你可以跳到 5 公尺高。
- **開車、騎腳踏車**：腳踏車比較慢、比較窄，可以騎上人行道，轉彎時車身會傾斜。撞到牆或樹，車子會彈回來。快撞到人時車子會停住，那個人會嚇一跳；一直這樣，他會生氣。
- 限制：只有球是真的物理物體。家具不會被撞動，人也不會被球撞倒。

### 時間和光影
- 時鐘會自己走（預設 1 秒 = 遊戲裡 2 分鐘），可以暫停、快轉，或拉滑桿直接跳到某個時間。
- 太陽和月亮會移動，影子、天空顏色、房間亮度跟著變。

### 改世界的例子
打開 `src/js/15-world-data.js`。

**搬沙發**：在設計圖 `cottage` 裡把沙發那一行改成下面這樣，5 間房子的沙發都會一起搬家並轉 90 度。人會自己走去新位置坐，球也會撞到新位置的沙發。

```js
{type:'sofa',x:.3,z:1.6,rot:1},
```

**多蓋一間房子**：在 `lots` 清單多寫一行，給它門牌、位置、顏色和住戶。`flip:true` 是把房子轉過來面向另一邊。

```js
{no:7,tpl:'cottage',x:-27,z:0,ext:0xf0e0d0,accent:0x335544,roof:0x333333,door:0x884422,balls:'few',people:[ ... ]},
```
