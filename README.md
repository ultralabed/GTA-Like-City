# GTA-Like-City：夕陽小房間

一間可以走進去逛的 3D 小公寓（客廳 + 臥室）。裡面住了兩個人，有會動的太陽和月亮，還有一個小小的物理引擎。

**線上玩：https://ultralabed.github.io/GTA-Like-City/** （推到 `main` 會自動更新）

也可以在自己電腦打開 `index.html`（需要網路，因為 3D 引擎 three.js 是從網路載入的）。

## 怎麼玩

| 你想做的事 | 電腦 | 手機 |
| --- | --- | --- |
| 走路 | `W` `A` `S` `D`，按住 `Shift` 會跑 | 左手拖 |
| 轉頭 | 點畫面鎖定滑鼠後移動滑鼠 | 右手拖 |
| 踢球 | 走近球，點它 | 點球 |
| 跟人打招呼 | 點那個人 | 點那個人 |
| 開關燈、電視 | 點它，或按左上角按鈕 | 同左 |
| 開門、關門 | 點門板 | 點門板 |

## 裡面有什麼

### 住在這裡的人
- **小美**（白天上班、有耐心）和 **阿傑**（上夜班、愛玩）。
- 他們**沒有固定時間表**（只有上班時間是固定的）。每個人有 5 個「需要」：體力、好玩、運動、平靜、照顧。需要會慢慢變少，他們會挑最缺的那個去補。
- 每件事都有**目標**：例如「看書」要看滿 1.2 小時、「踢籃球」要踢到 3 下、「睡覺」要睡到體力滿。名牌上會顯示完成幾 %。
- **被打斷會有不同反應**，看是什麼事、是誰、心情好不好、第幾次：
  - 你打招呼 → 心情好會揮手，心情差會說不想講話。
  - 你關電視 → 第一次會抗議然後自己開回來，第二次就放棄去做別的事。
  - 你用球踢到人 → 阿傑會加入一起踢，踢完再回去做原本的事；小美會警告你，第三次就生氣走開。
  - 睡覺時吵他 → 第一次沒醒，第二次抱怨，第三次睡不著起來。
  - 你擋路 → 會說借過；有耐心的人等比較久。
  - 天黑你關燈 → 會說好暗，然後開回來。
- 按「想法」按鈕，可以看到每個人現在的目標和 5 個需要的數字。

### 物理
- **重力**：球會往下掉、會彈。可以切換 地球 / 月球 / 無重力。
- **吸引力**：打開「引力球」，它會把別的球吸過來。公式是 `F = G·m1·m2 / r²`。
- **作用力與反作用力**：兩個東西相撞，各自被推一樣大、方向相反的力。輕的跑得快，重的幾乎不動。左上角會寫出每次碰撞誰推了誰、推多大。
- 限制：只有球是真的物理物體。家具不會被撞動，人也不會被球撞倒。

### 時間和光影
- 時鐘會自己走（預設 1 秒 = 遊戲裡 2 分鐘），可以暫停、快轉，或拉滑桿直接跳到某個時間。
- 太陽和月亮會移動，影子、天空顏色、房間亮度跟著變。

## 檔案

改程式請改 `src/` 裡的小檔案，然後跑 `python3 build.py`，它會把小檔案黏成 `room.html` 和 `index.html`。

| 檔案 | 裡面是什麼 |
| --- | --- |
| `src/page.html` | 網頁的外殼：樣式、按鈕 |
| `src/js/00-core.js` | 開機：畫布、鏡頭 |
| `src/js/10-textures.js` `11-materials.js` | 木頭、布、天空這些花紋和材質 |
| **`src/js/15-house-data.js`** | **這間房子的資料：有哪些房間、每間多大、牆上哪裡開窗開門、家具放哪、有哪些球、住誰。想改房子就改這裡** |
| `src/js/20-build.js` | 把家具放進房間的工具（可以移動、可以轉向） |
| `src/js/21-prefabs.js` | 家具積木：沙發、電視櫃、書櫃、床、衣櫃、盆栽、立燈、霓虹燈、門… |
| `src/js/22-shell.js` | 照資料蓋出每個房間的地板、牆、窗戶、門洞，再把家具一個個放進去 |
| `src/js/30-sky-lights.js` `31-state-time.js` | 天空、太陽、時鐘、開關 |
| `src/js/40-physics.js` | 物理引擎 |
| `src/js/50-people.js` | 人的身體、動作、找路 |
| `src/js/51-minds.js` | 人的大腦：需要、目標、被打斷的反應 |
| `src/js/60-render.js` `70-controls.js` `80-tv.js` `90-main.js` | 畫面特效、操作、電視節目、主迴圈 |
| `room.html` `index.html` | 黏好的成品（不要直接改） |
| `ROADMAP.md` | 三個階段的計畫和進度 |

### 改房間的例子
打開 `src/js/15-house-data.js`，把沙發那一行改成：

```js
{type:'sofa',x:.3,z:1.6,rot:1},
```

沙發就會搬到新位置並轉 90 度。人會自己走去新位置坐，球也會撞到新位置的沙發，不用改別的地方。

想加一個房間，就在 `rooms` 清單裡多寫一個：給它位置、大小、四面牆、家具清單。
